Quem disse?

Um jogo de frases de personagens bíblicos

Como jogar

  1. Uma pessoa fica com o celular e é o leitor da rodada.
  2. O leitor vê o personagem e escolhe uma frase para ler por vez, sem revelar quem é.
  3. Se alguém errar, o leitor lê outra frase para o próximo jogador.
  4. Quem acertar marca 1 ponto. Depois, começa uma nova rodada com outro personagem e outro leitor.

Dica: mantenha o celular voltado para o leitor para que os outros jogadores não vejam o personagem.

Personagem da rodada

Toque em uma frase depois de lê-la para marcá-la como usada.

Fim da partida!

Todos os personagens disponíveis já foram utilizados. Para começar uma nova partida, os personagens poderão ser sorteados novamente.
